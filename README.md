# 宠物指针 Pet Cursor

把 Mac 的鼠标指针换成一只宠物：点链接、打字、拖动、加载中各有不同的表情和动作。鼠标停 5 秒，宠物会跳舞，再过一会儿睡着，一动鼠标就醒。

内置橘猫、奶牛猫、边牧、阿比（比格）四只，也能用一张 AI 生成的姿势图换成你自家的宠物。

![四只宠物的 16 种指针状态](docs/overview.png)

- macOS 13 及以上，Intel 和 Apple 芯片都能用
- 只在菜单栏出现，不需要任何系统权限，不联网，不收集数据

## 下载安装

1. 到 [Releases](../../releases/latest) 下载 `PetCursor-Mac.zip`，解压后把「宠物指针.app」拖进「应用程序」
2. 双击打开。App 没有苹果开发者签名，系统会拦一下：先关掉提示，再到「系统设置 → 隐私与安全性」最下面点「仍要打开」
3. 指针马上换好，菜单栏多出一个宠物小图标，切换宠物、开关跳舞、开机自启都在这里

详细步骤、卸载和常见问题见 [安装说明](app/安装说明.txt)。

## 换成你自己的宠物

1. 菜单栏图标 →「切换宠物」→「复制出图提示词」，在 ChatGPT、豆包或 Gemini 里上传宠物照片、粘贴提示词，生成一张 4 列 5 行的姿势图
2. 回到菜单「切换宠物」→「添加宠物…」，选这张图、起个名字，几秒后就换上了

自定义宠物的指针符号由 App 统一绘制，点击点固定，换什么动物都对得准；链接、张开爪、抓紧爪使用独立的爪子图，不要求 AI 画举爪姿势。内置宠物保留经典造型。

## 从源码编译

需要 Xcode Command Line Tools（`xcode-select --install`）和带 Pillow 的 python3（只用来生成 App 图标）。

```bash
bash app/build_app.sh
```

产物在 `dist/`：`宠物指针.app` 和打包好的 `PetCursor-Mac.zip`。`skins/` 下的每个宠物文件夹都会内置进 App。

## 目录

| 路径 | 内容 |
|---|---|
| `app/` | App 源码（Swift）、编译脚本、安装说明 |
| `skins/` | 内置宠物，一个文件夹一只 |
| `tools/` | 早期用的 Python 换皮脚本，新宠物用 App 菜单即可 |
